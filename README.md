# 后室RPG攻略速查

给《狐霖的后室 RPG》玩家使用的网页攻略速查。

资料更新：2026-11-09。资料可能与后续游戏更新存在差异。

## 怎么使用

- 在线打开页面后，直接搜索层级、事件、怪物、物品、委托或角色。
- 找不到想看的内容时，可以换一个关键词，或使用页面里的分类筛选。
- 点击卡片可以展开更多内容；事件卡里通常会列出前提、检定、成功结果、失败结果和可能的替代结果。
- 页面支持简体／繁体切换。
- 如果下载后打开，直接用浏览器打开 `index.html` 即可，不需要安装程序，也不需要登录。

## 页面内容

首页按栏目进入各个速查页面，也可以先选搜索范围、输入关键词后跳转。各板块独立打开，避免所有内容挤在一页。

- 层级事件与探索选项
- 结局速查
- 怪物弱点、抗性与应对方式
- 怪物前缀词条说明
- 委托攻略
- 物品用途与详细数值
- 物品合成、强化与修理配方
- 角色分类与选择参考
- 探索提示术语

各页面提供查资料需要的条件、结果、数值和注意事项。

这是给玩家查资料用的速查页面，优先按自己当前的角色、物资和状态选择路线；遇到不同情况时，建议同时查看事件的前提和结果说明。
